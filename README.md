# Juegos de Rehabilitación Cognitiva

Aplicación web didáctica diseñada para ayudar a personas que han sufrido un ACV (accidente cerebrovascular) en su proceso de recuperación cognitiva.  
A través de juegos simples, progresivos y motivadores, se ejercitan **memoria**, **atención** y **coordinación**.

Ideal para uso en tablets (iPad y Android) y computadoras. Interfaz táctil, botones grandes y diseño amigable.

---

## 🎯 Objetivo

Brindar una herramienta terapéutica accesible y gratuita que permita:
- Reactivar y ejercitar funciones cognitivas afectadas
- Trabajar de forma lúdica y sin frustración
- Progresar de forma gradual según el nivel del usuario
- Usarse fácilmente en el hogar o en sesiones de terapia

---

## 🎮 Juegos Incluidos

### 1. Memoria
- Encuentra las parejas de cartas
- Niveles con 4, 6 y 8 pares
- Contador de intentos y tiempo

### 2. Atención
- Encuentra el elemento diferente o el que aparece/desaparece
- Dificultad progressive
- Feedback inmediato

### 3. Coordinación
- Toca los objetos que aparecen en pantalla
- Entrenamiento de tiempo de reacción y precisión
- Niveles de velocidad creciente

## 🚀 Cómo usarlo

1. Descarga o clona este repositorio
2. Abre el archivo `rehabilitacion-cognitiva.html` en cualquier navegador moderno
3. ¡Listo! No necesita instalación ni conexión a internet

## 🌐 Desplegar online (gratis)

Puedes subir el proyecto a cualquiera de estas plataformas:

### Vercel
1. Crea una cuenta en [vercel.com](https://vercel.com)
2. Conecta tu repositorio de GitHub
3. Despliega (Framework Preset: Other)

### Netlify
1. Arrastra y suelta la carpeta del proyecto en [netlify.com/drop](https://app.netlify.com/drop)
2. O conecta el repositorio de GitHub

### GitHub Pages
1. Ve a Settings → Pages
2. Elige la rama `main` y la carpeta `/root`
3. Guarda y espera unos minutos
